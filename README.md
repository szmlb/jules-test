# Reinforcement Learning: CartPole with REINFORCE

This project demonstrates a simple continuous reinforcement learning algorithm (REINFORCE) applied to the classic CartPole balancing problem. The goal is to train an agent to balance a pole upright on a movable cart. The environment is custom-built and the agent uses a policy network implemented with PyTorch.

## Project Structure

-   `cartpole/`: Main Python package.
    -   `cartpole_env.py`: Implements the CartPole environment dynamics, state transitions, and rewards.
    -   `policy.py`: Defines the neural network policy that maps states to actions (using PyTorch). The policy outputs parameters for a continuous action distribution.
    -   `agent.py`: Implements the REINFORCE agent, which learns by collecting experience (state, action, reward sequences) and updating the policy based on discounted returns.
    -   `main.py`: The main script to initialize the environment and agent, run the training loop, log progress, and visualize results including training rewards.
    -   `utils/visualization.py`: Contains the `CartPoleVisualizer` class for rendering the CartPole environment using Matplotlib.
-   `cartpole/tests/`: Contains unit tests for the environment (`test_cartpole_env.py`), policy network (`test_policy.py`), and agent (`test_agent.py`).
-   `README.md`: This file.
-   `requirements.txt`: Lists the Python dependencies (NumPy, PyTorch, Matplotlib) required for this project.
-   `cartpole_training_rewards.png`: This plot is generated by `main.py` after training, showing the learning progress. (Note: This file will only appear after you run the training script).

## Algorithm

The agent uses the **REINFORCE** algorithm, also known as Monte Carlo Policy Gradient. This is an on-policy algorithm that learns by:
1.  Sampling full episodes of experience using the current policy.
2.  For each step in an episode, calculating the discounted cumulative future reward (Return, Gt).
3.  Updating the policy network's parameters by performing gradient ascent on the objective `log(pi(action | state)) * Gt`.
The policy network in this project outputs the mean and standard deviation for a Gaussian distribution, from which continuous actions (forces applied to the cart) are sampled.

## Setup and Installation

1.  **Clone the repository:**
    If you have access to the repository, clone it using:
    ```bash
    git clone <repository_url>
    cd <repository_directory_name>
    ```
    (Replace `<repository_url>` and `<repository_directory_name>` with actual values if applicable. If working locally, you might skip this step.)

2.  **Create and activate a virtual environment (recommended):**
    This helps manage project dependencies without affecting your global Python installation.
    ```bash
    python -m venv venv
    ```
    -   On macOS and Linux:
        ```bash
        source venv/bin/activate
        ```
    -   On Windows:
        ```bash
        venv\Scripts\activate
        ```

3.  **Install dependencies:**
    With your virtual environment activated, install the required packages:
    ```bash
    pip install -r requirements.txt
    ```

## How to Run

1.  **Start the training process:**
    Navigate to the root directory of the project (the directory containing the `cartpole` folder and `requirements.txt`).
    Run the main script using:
    ```bash
    python cartpole/main.py
    ```
    Alternatively, you can run it as a module from the project's root directory (ensure your `PYTHONPATH` includes the project root or use the command from the root):
    ```bash
    python -m cartpole.main
    ```

2.  **Observe Training:**
    -   The script will print training progress to the console, including the episode number, total reward for recent episodes, and average rewards over logging intervals.
    -   Some episodes will be rendered graphically using Matplotlib (a window showing the CartPole simulation will appear). This is controlled by the `render_every_n_episodes` setting in `main.py`.
    -   Upon completion of training, a plot named `cartpole_training_rewards.png` will be saved in the project's root directory. This plot visualizes the reward per episode and a moving average of rewards, providing insight into the agent's learning performance.

## How to Run Tests

To verify that all components of the project are functioning as expected, you can run the suite of unit tests.
From the project's root directory, execute:
```bash
python -m unittest discover cartpole/tests
```
This command will automatically find and run all tests located in the `cartpole/tests` directory. You should see output indicating the number of tests run and their status (e.g., "OK" if all tests pass).
